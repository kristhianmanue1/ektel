## Decisión humana

El dueño autoriza formalmente **EKTEL M2 = CLOSED** y acepta
**G-M2-01..G-M2-15 = 15/15 CONFORMING**, dentro del threat model y claims
ratificados. Este es el acto separado que faltaba al pre-cierre; no una nueva
evaluación de tests ni una ronda correctiva.

```text
G-M2-01..15 = 15/15 CONFORMING
G-M2-15 = CONFORMING
M2 = CLOSED
M3 = BLOCKED / NOT AUTHORIZED
```

## Limitaciones y provenance preservadas

```text
R13-STRONG = KNOWN-LIMITATION / OUT-OF-THREAT-MODEL / NO-CLAIM
R13-STRONG.provenance = BLOCKED-BY-NORMATIVE-GAP
```

El gap corresponde a la propiedad fuerte de aislamiento frente a código Python
arbitrario co-residente en el mismo intérprete. El cierre no resuelve esa
propiedad ni declara R13 fuerte satisfecha. R13/R14 conservan sus resultados
históricos NOT-SATISFIED; R12/R15/R16 conservan SATISFIED en el modelo ratificado,
con la sustitución de obligaciones residuales descrita en la adjudicación.

EKTEL M2 no afirma proporcionar:

- aislamiento frente a introspección/modificación arbitraria dentro del
  intérprete coordinador;
- aislamiento interproceso derivado de R15;
- protección frente a sustitución arbitraria de componentes confiables;
- recuperación durable del lifecycle local no especificada;
- latencia máxima acotada entre spawn confirmado y retorno de Started.

Estas limitaciones no se convierten en garantías mediante el cierre. Se
preservan igualmente las demás limitaciones del expediente: pérdida de evidencia
de emisión implica fail-closed, compromiso del Host no prueba efectos futuros
del SO, degradaciones/escapes POSIX declarados, payload distinto de RSS y límites
de cobertura empírica. El cierre no expande el threat model ratificado en la
[decisión R13-STRONG/R15/R16](ratificacion-r13-strong-r15-r16-2026-09-10.md).

## Alcance autorizado y parada

El acto confirma **únicamente M2**. No autoriza M3, M4, tags, releases,
expansión del threat model, IPC nuevo, sandboxing adicional, wire/schema nuevos
ni resolución de R13-STRONG. Cualquier fase posterior requiere autorización
separada. Cerrar M2 no inicia automáticamente M3 ni asigna allí el gap fuerte.

El registro autorizado es exclusivamente documental: esta acta, índice de
gobernanza, estado de M2 y puntero del expediente. Se preservan íntegros el
pre-cierre y los informes históricos. No se modifican implementación, tests,
contracts, schemas ni MANIFEST-ROOT; no se generan nuevas raíces correctivas.

Antes de registrar se comprobaron HEAD y remoto contra el pre-cierre aceptado,
árbol limpio, MANIFEST-ROOT y ausencia de diff de implementación respecto de
CORRECTIVE-REVIEW-ROOT. La publicación exige verificar de nuevo HEAD ==
origin/main, árbol limpio, las 98 entradas del manifiesto y la identidad cerrada.
El SHA documental de esta acta se reporta después del commit/push, sin referencia
circular dentro del propio commit. Después de esa verificación, detenerse.
