- **Fecha:** 2026-09-08.
- **Veredicto:** `F0-A-CLOSED`.
- **P1 dentro de alcance:** ninguno.

## Decisión

F0-A satisface el DoD del mandato: existe corpus trazable, vocabulario,
Threat Model, Authority/Trust Model, clasificación de tres paradigmas,
cuestiones abiertas, Research Log, Decision Log y Artifact Manifest. La ronda
independiente y su reconciliación están registradas.

El corpus desfavorece **H-common fuerte**. **H-family** es la inclinación
provisional; **H-profiles** permanece viable si demuestra en F0-B un núcleo
operacional no trivial. Esta decisión no elige arquitectura, Core, schema ni
wire format.

## Stop decision

Se detiene el trabajo. No se solicita ni se presume autorización para F0-B.
Permanecen expresamente no autorizados:

- F0-B, F0-C y F0-D;
- M2 y M3;
- cambios funcionales, contratos, schemas, tests o ADR de EKTEL;
- cambios en AN-KLA, SKEVI, Skopos, Ágora u otros consumidores;
- branch, commit, push, PR, merge, release y publicación.

Un acto humano separado sería necesario para cualquier fase posterior.
